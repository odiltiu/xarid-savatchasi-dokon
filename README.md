# 🛒 Xarid Savatchasi — Onlayn Do'kon

Ushbu loyiha **React 19** va **Context API** yordamida yaratilgan zamonaviy elektron xarid savatchasi tizimi.

## 🚀 Texnologiyalar

- **React 19**
- **React Context API (`CartProvider`)**
- **Tailwind CSS**
- **Lucide Icons**
- **Vite**

## 🌟 Imkoniyatlar

- Mahsulotlar katalogini ko'rish va saralash
- Mahsulotlarni xarid savatchasiga qo'shish
- Savatchadagi mahsulotlar sonini ko'paytirish yoki kamaytirish
- Savatchadagi mahsulotlarni o'chirish
- Umumiy summani avtomatik hisoblab borish
- Qulay savatcha modal oynasi

## 💻 Ishga tushirish

```bash
# Kutubxonalarni o'rnatish
npm install

# Dev rejimida ishga tushirish
npm run dev

# Production uchun build
npm run build
```
